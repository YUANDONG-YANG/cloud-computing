## 1. Phase Overview

Phase 2 builds on Phase 1 (local development). The goal is to **move the solution to Azure Cloud** and build a **web-based dashboard** displaying visual insights generated by the Azure Function.

### Phase 1 → Phase 2 Transition

| Component         | Phase 1 (Local)                    | Phase 2 (Cloud)                              |
|--------------------|-------------------------------------|-----------------------------------------------|
| Function Execution | Localhost (Azure Core Tools)       | Azure Functions deployed to Azure portal      |
| Blob Storage       | Azurite (local emulator)           | Azure Blob Storage account                    |
| Dataset Access     | Local blob container               | Public/secured blob container in Azure        |
| Output             | Local console/logs and files       | Dashboard UI in browser                       |
| Goal               | Build and test functionality       | Deploy, visualize, and interact in the cloud  |

## 3. Cloud Setup Steps Required

1. Create/Use Azure Subscription and Resource Group (e.g., `diet-analysis-rg`)
2. Provision Azure Function App, Azure Storage Account, and Static Web App/App Service
3. Deploy the Azure Function
4. Update storage connection strings to point to live Azure Blob Storage
5. Test Azure Function endpoint using Postman or browser
6. Develop dashboard UI and fetch data from Azure Function endpoint

---

## 4. Dashboard Requirements

- Display at least **3 data visualizations** from the Azure Function (bar chart, line/pie chart, scatter/heatmap)
- Include **interaction controls** (dataset filters, refresh buttons)
- Show **metadata** such as function execution time
- Be deployed and **publicly accessible** via Azure Static Web App or App Service

## 9. Key Technical Components

### Backend (Azure Function)
- HTTP-triggered function reading from Azure Blob Storage
- Returns JSON with cleaned data, aggregations, chart data
- Connection string pointing to Azure Storage (not Azurite)

### Frontend (Static Web App)
- HTML/CSS/JS dashboard
- Fetches data from Azure Function endpoint via fetch() API
- Renders charts using Chart.js or inline SVG
- Includes filters, search, pagination

### Storage
- Azure Blob Storage container holding All_Diets.csv
- Connection via Azure Storage SDK or REST API
