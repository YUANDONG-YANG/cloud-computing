2. Plain-language glossary (read this first)

TermWhat it means, in one sentence
Dataset (All_Diets.csv)A spreadsheet of 7,806 recipes. Each row has a diet type (keto, vegan…), cuisine, and grams of protein, carbs and fat.
Pandas / Python scriptA program that reads the spreadsheet and does the maths for us (averages, rankings).
Docker / containerA sealed box holding our program and everything it needs, so it runs the same on any computer.
Docker ComposeA recipe file that starts several containers together with one command.
RegistryAn app store for containers. We used a local one instead of Docker Hub.
AzuriteA free fake copy of Microsoft Azure's file storage that runs on our own laptop, so we do not need to pay for or use real Azure.
Blob storageCloud "folders" for files. Our CSV is stored there.
Serverless functionA small program that runs only when asked, reads a file from cloud storage and writes results. Ours is started manually.
Simulated NoSQL databaseA file of JSON records (results.json) that stands in for a cloud database such as Cosmos DB.
CI/CD, GitHub ActionsA robot on GitHub that, every time we upload code, automatically builds it, tests it and runs it, then reports pass or fail.

3. Before you record (everyone)

Face clearly visible, good light in front of you (not behind), quiet room.
Microphone works; do a 10-second test recording and listen to it.
Close chat apps, email, and anything private. Never show passwords, tokens or secrets.
Screen text is readable: zoom the browser to 125–150%; for the terminal use a large font.
The screen date and time must be visible during the demos (Ubuntu top bar clock or Windows taskbar).
Everyone has the files open and ready: Project1-Presentation.html, Enhancement-Report.pdf, the GitHub repository page, Contribution-Report.html.

How to record with Microsoft Teams

  1. Create a Teams meeting (Calendar → Meet now). Everyone joins and turns their camera on.
  2. Click … (More) → Record and transcribe → Start recording.
  3. When it is your turn, click Share → pick Window (the one you want to show), then speak. Click Stop sharing when done. Your camera stays on.
  4. After the last person, click … → Stop recording and leave the meeting.
  5. The recording appears in the meeting chat (and in OneDrive) after a few minutes. Download the .mp4 and play it once to check that all three faces and the screens are visible.
Tip: record each person's part as one take. If someone makes a mistake, pause two seconds, repeat the sentence, and we will leave it or re-record that part. Practise once out loud before the real recording.

7. Likely questions and short answers

QuestionSimple answer
Did you use real Azure?No. Azurite simulates Azure Blob storage on our own machine, and a JSON file simulates the NoSQL database.
Is the function really serverless?It follows the same design (read from storage, process, save), but we start it manually; Azurite has no real triggers.
Why is Mediterranean the winner in total but keto in average?Mediterranean has more recipes, so the total is larger. Keto recipes have more protein on average.
Why a local registry, not Docker Hub?The assignment allows either. A local registry needs no account or secrets.
What does CI/CD do?It automatically builds and tests our code on every upload and tells us if something breaks.
What did you not measure?Cold-start time and cloud cost. We only measured image size and calculation time.
