Team video — demonstration guide

Suggested 7–9 minutes; adapt to the instructor’s presentation requirements. Each member must appear on camera and explain their actual work. Start with names, course and project title.

  1. Architecture (45 seconds): explain the CSV → analysis and Blob → function → JSON paths. Say explicitly that Azure services are simulated locally.
  2. Analysis (2 minutes): run docker compose run --rm analysis; show all three charts, the top-five CSV, cleaning rules and undefined ratios. Explain why keto wins the mean comparison while Mediterranean wins the total comparison.
  3. Container deployment (1 minute): show Dockerfile and Compose; run docker compose ps. Explain output mounts and the local registry push/pull.
  4. Function (1 minute): run upload, then the function; show five JSON documents. Explain why the Compose endpoint is azurite, and why this manual function is not a real Azure trigger.
  5. CI/CD (1 minute): show workflow stages and a REAL successful GitHub Actions run after pushing. Show pytest and the batch/Blob comparison. Do not present local logs as remote Actions evidence.
  6. Enhancements (1 minute): show the one-page report and actual size/timing data. Explain benchmark scope and the replicated workload.
  7. Contributions and close (45 seconds): each person identifies their own changes and reviews, supported by real commits/PRs.

Recording checklist: faces visible; terminal date/time visible; readable text; microphone checked; no account tokens displayed; video plays after export; include the file or approved link in the final submission.
